PRIVACYプライバシーポリシー

Bug&Lavi Project（以下「当プロジェクト」）は、当ウェブサイト（https://bug-and-lavi-project.com/、以下「当サイト」）および YouTube チャンネル「Lavi AI singer-songwriter」（以下「当チャンネル」）における利用者の個人情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」）を定めます。

1. 取得する情報

当サイトでは、お問い合わせフォームの利用時に、以下の情報を取得します。

  • 件名
  • お名前・フリガナ
  • メールアドレス
  • お問い合わせ内容

上記は、利用者がフォームに入力・送信した場合にのみ取得します。入力は任意であり、送信しない限り取得することはありません。

2. 利用目的

取得した個人情報は、以下の目的の範囲でのみ利用します。

  • お問い合わせへの回答・連絡のため
  • 当プロジェクトの運営・活動に関する必要な連絡のため

利用目的の範囲を超えて利用する場合は、あらかじめご本人の同意を得るものとします。

3. 第三者への提供

当プロジェクトは、法令に基づく場合および第5項に定める場合を除き、ご本人の同意なく個人情報を第三者に提供しません。

4. 外部サービスの利用

当サイトは、運営上、以下の外部サービスを利用しています。これらのサービスにおける情報の取り扱いは、各提供者の定めるポリシーに従います。

  • お問い合わせフォーム：フォームの送信・管理にフォーム作成サービス（ssgform）を利用しています。送信内容は同サービスを通じて当プロジェクトに送られます。
  • 音楽配信・動画の埋め込み／リンク：Spotify、Apple Music、YouTube 等のサービスへのリンクおよび埋め込みを行う場合があります。リンク先・埋め込み先での情報取得は各サービスのポリシーに従います。
  • 外部リソースの読み込み：表示のため、Google Fonts（Google）のフォント、Font Awesome（cdnjs／Cloudflare）のアイコン、Apple Music・YouTube が提供するジャケット画像・動画サムネイル画像を、各社のサーバーから読み込んでいます。読み込みの際、利用者の IP アドレスやブラウザの情報が各社に送信されます。
  • 迷惑行為の防止：お問い合わせフォームでは、スパム等の防止のため Google reCAPTCHA を利用しています。利用にあたり、端末やブラウザの情報が Google に送信されます（Google プライバシーポリシー、利用規約）。
  • アクセス解析：サイトの利用状況を把握するため、Cloudflare Web Analytics を利用しています。これは Cookie を使用せず、個人を特定しない形で、ページの表示回数・アクセス元・利用環境などの統計情報を計測します。

5. YouTube API サービスの利用

当プロジェクトは、当チャンネルに寄せられたコメントの確認と返信のため、YouTube API サービスを利用しています。

（1）取得する情報

当チャンネルの動画に投稿されたコメントについて、次の情報を YouTube から取得します。いずれも YouTube 上で公開されている情報です。

  • コメントの本文、投稿日時、高評価の数
  • 投稿者の表示名
  • コメントに付いた返信の内容
  • コメントが付いた動画のタイトル

投稿者のチャンネル ID は、当チャンネルからの返信かどうかを見分けるためだけに使い、保存しません。メールアドレスなど、YouTube 上で公開されていない情報は取得しません。

（2）利用目的

取得した情報は、コメントへの返信を作成し、当チャンネルから投稿するためだけに利用します。広告や分析など、他の目的には利用しません。

（3）AI の利用

返信文の作成にあたり、取得したコメントの内容を AI サービス（Anthropic 社の Claude）で処理します。返信は、運営者が内容を確認したうえで投稿します。AI サービスでの情報の取り扱いは、Anthropic 社のプライバシーポリシー（https://www.anthropic.com/legal/privacy）に従います。

（4）保存と削除

取得した情報は、運営者の端末に保存し、次回の取得時に上書きします。取得から30日以内に、更新または削除します。二重投稿を防ぐため、返信の記録（返信先のコメントの ID と、返信した内容）は保管します。YouTube 上でコメントを削除された場合、次回の取得以降、そのコメントの内容は当プロジェクトの手元に残りません。当プロジェクトが保存している情報の削除をご希望の場合は、第10項の窓口までご連絡ください。

（5）第三者への提供

（3）の AI サービスでの処理を除き、取得した情報を第三者に提供しません。

（6）関連する規約

YouTube API サービスの利用には、YouTube 利用規約（https://www.youtube.com/t/terms）および Google プライバシーポリシー（https://policies.google.com/privacy）が適用されます。

6. Cookie（クッキー）等について

当サイト自体は、利用者を追跡する目的での Cookie を使用していません。 ただし、第4項の埋め込みコンテンツや外部サービスが、各社の方針に基づいて Cookie 等を利用する場合があります。 ブラウザの設定により Cookie を無効化することができますが、その場合、一部の機能が正しく動作しないことがあります。

7. 個人情報の管理

当プロジェクトは、取得した個人情報の漏えい・滅失・毀損の防止その他の安全管理のため、必要かつ適切な措置を講じます。

8. 開示・訂正・削除の請求

ご本人から、個人情報の開示・訂正・利用停止・削除等のご請求があった場合は、ご本人であることを確認のうえ、合理的な範囲で速やかに対応します。 ご請求は、第10項の窓口までご連絡ください。

9. 免責事項

当サイトからリンクする外部サイトおよび外部サービスにおいて取得・利用される情報については、当プロジェクトは責任を負いません。各サービスのプライバシーポリシーをご確認ください。

10. 運営者情報・お問い合わせ窓口

  • 運営者：Bug&Lavi Project
  • お問い合わせ窓口：お問い合わせフォーム

11. 本ポリシーの変更

当プロジェクトは、必要に応じて本ポリシーを変更することがあります。変更後の内容は、当サイトに掲載した時点から効力を生じるものとします。
